# KemperControlDAW

KemperControlDAW is an open-source JUCE MIDI control interface for the Kemper
Player, designed to bring clear, visual Kemper control directly into a DAW.

## Features

- Bank and slot selection with discrete values from 1–124 and 1–5.
- Direct rig selection for slots 1–5.
- Effect slot controls for A, B, C, D, X, MOD, DLY and REV.
- Morph, expression, wah and gain controls.
- Dedicated Morph Switch control for the currently selected rig.
- Extra commands I, II, III and IIII.
- Dedicated looper controls for Rec / Play, Stop, Trigger, Reverse, Half,
  Undo and Erase.
- MIDI output and channel selection directly from the interface.
- Automation-friendly parameters for programming changes throughout a song or
  backing track.

KemperControlDAW is designed for use with Logic Pro, Ableton Live and other
DAWs. It provides a clear interface for controlling the Kemper Player without
having to enter MIDI CC values manually.

## Releases

Precompiled plugin versions are available in the
[Releases](https://github.com/adriendoespostrock/KemperControlDAW/releases)
section. Download the appropriate release for your system and follow the
installation information included with that release.

## About

KemperControlDAW was developed by Adrien Deurveilher, guitarist of
[When Waves Collide](https://www.youtube.com/@WhenWavesCollide).

The project is intended for musicians who want to automate Kemper changes
throughout a song while keeping the control interface inside their DAW.
